# 框架验收与剩余工作

本记录对应工程框架，不将模拟数据测试当作真实知乎 API 验收。

2026-09-12 本地验证：代码规范检查、TypeScript 检查、生产构建及 HTTP smoke 已完成。浏览器实际走通了本科报考的两轮澄清、确认、演示生成、刷新恢复、反馈，以及修改为校园生活后生成新答案并保留旧答案；375px 视口实测没有横向溢出。具体测试结果以当前 `npm run check` 输出为准。

| 范围 | 验证方式 |
| --- | --- |

## 当前限制

- 未提供/调用真实知乎凭证；没有宣称检索覆盖、模型权限、延迟或引用语义已通过验收。
- 规则提取支持典型大学问题，复杂否定句、自由输入冲突、多学校名称仍需专门设计；不宣称完成通用 NLU。
- 澄清由模板实现，未接入 fast 模型；最终模型 JSON 不稳定时使用摘要降级。
- 使用分阶段反馈，没有逐字流式输出。
- 招生官方来源的补充搜索尚未接入，因此不提供精确招生/录取结论。
- 部署目标是单实例持久磁盘；尚未发布公网 Demo。公网运行前需确认 HTTPS、入口限流、总预算、数据库备份及真实 API 行为。
- P1 延伸追问/多校比较和 P2 OAuth/画像/语音/多 Agent 不在此次框架范围。
- 暂未完成 20 条人工标注效果评估或 6 组同题不同目的的真实答案比较。

## 复验

1. `npm ci && npm run check && npm run build`。
2. 开发模式启动后，执行 `npm run test:smoke`。
3. 参照 [演示脚本](DEMO.md) 走桌面和手机流程。
4. 准备真实凭证后，在 live 模式核实权限、摘要、来源、模型结果；不要用 demo 通过记录替代 M0/M2。
