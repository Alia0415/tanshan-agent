**两份 Offer，怎么选？** 以一个虚构求职困境，展示三个独立入口的用途。

| 时间 | 功能 | 展示重点 |
| --- | --- | --- |
| 00:00–00:03 | 开场 | 三个入口并列，按需进入 |
| 00:03–00:23 | Agent 问答 | 追问处境、补充条件、知乎帖子推荐、筛选说明与原帖入口 |
| 00:23–00:40 | 阅读助手 | 独立面试问题、关注点、阅读路线、摘要思维导图 |
| 00:40–00:57 | 观点圆桌 | 独立话题、不同立场、用户插话、相关角色回应与来源 |
| 00:57–01:00 | 收尾 | 三种能力，独立使用、按需关联 |

视频为 **60 秒 / 1920×1080 / 30 fps / H.264 + AAC**，无配音，含原创轻配乐。对应本次选定的 V4 版本。

这是以真实产品内容和原生角色素材制作的**流程动效演示**，并非单次连续实时录屏；等待过程做了节奏压缩。演示顺序不表示三个入口存在必经流程，也不表示完整上下文自动在入口之间传递。

Offer 的薪资、通勤及个人处境为虚构演示设定。推荐帖子与阅读文章来自实际产品返回，导图基于知乎搜索摘要生成；原文镜头展示入口，不代表已获取全文。圆桌由模型模拟不同立场，引用可追溯不等于独立事实核验。

在线体验使用原创样例，与视频中的真实知乎资料模式有所不同。体验范围见 [公开体验说明](../ONLINE_DEMO.md)；本地演示步骤见 [演示指南](../DEMO.md)。
