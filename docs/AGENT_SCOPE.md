# Agent 范围说明

2026-09-12 用户明确：产品要作为知乎站内 Agent 使用，不限于学习问题，并使用知乎提供的 Skill。本说明覆盖原 PRD 中的独立大学问答应用定位。

## 当前产品约定

1. 入口目标是知乎站内对话。网页仅用于本地验证，不能用网页运行成功代替站内集成成功。
2. 用户自然提问 → 判断是否需要澄清 → 最多两轮可跳过追问 → 检索知乎帖子 → 帖子列表与可展开的辅助总结 → 继续补充或修改条件。
3. 通用条件为讨论对象、回答目的、背景、限制和关注点。大学等领域可以作为实例，不作为固定表单或路由前提。
4. 自由文本原话进入搜索与回答；没有识别出的条件不丢失，也不冒充已经理解。
5. 根据用户后续要求，最终检索对象仅为知乎帖子：问题、回答与专栏文章。使用知乎 Skill 文档中的知乎搜索，保留标题、作者、摘要与原帖链接，不调用全网搜索、不抓取全文。需要权威或时效资料而知乎帖子不足时说明局限。本地后端用知乎直答生成辅助总结；宿主具备模型时可替换生成器。

## 框架与实际接入的区别

已实现的 `receiveAgentMessage` 是内部 TypeScript 接口。`POST /api/agent/messages` 是调试适配器，使用应用自己的 Cookie 和字段。它们均不是已验证的知乎站内协议。

尚缺站内创建入口对应的协议：宿主如何托管 Agent、工具如何绑定、入站身份如何验签、会话与事件字段、消息输出形式以及发布流程。提供这些信息后才能完成最后一层适配与站内验收。

人设与工具说明可先在 `agent/` 审阅。没有凭证时只验收模拟对话，不声称调用了官方服务或读取了站内用户资料。
