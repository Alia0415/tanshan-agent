# 文档导航

[返回项目首页](../README.md) · [本地运行](GETTING_STARTED.md) · [参与贡献](../CONTRIBUTING.md)

探山包含 **Agent 问答、阅读助手、观点圆桌** 三个独立入口。它们可以围绕同一话题使用；跨入口携带问题标题，由用户确认后提交，不要求先走完另外两个功能。
