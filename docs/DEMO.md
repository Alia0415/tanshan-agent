# 演示与联调

目前为本地 Agent 调试，不代表已经进入知乎站内；demo 模式不调用真实接口。

## 卡片调试

1. 输入「如何评价远程办公？」；选择「比较与选择」。
2. 补充「工作三年，正在考虑换工作」，选择实际体验/长期影响；核对聚焦问题并开始分析。
3. 修改条件为「需要兼顾照顾家人」，重新分析。确认旧答案保留且新回答对应新版本。
4. 输入「预算 6000 元，想买旅行用的相机」；明确问题直接进入回答。
5. 输入宽泛问题并跳过，确认无需填写所有背景字段。
6. 刷新会话、提交反馈；在手机宽度检查输入和选项。

## 文字对话

`npm run test:smoke` 会同时验证 `/api/agent/messages` 的创建、文字跳过和结果返回。服务测试覆盖「提问 → 目的选项 → 自由文字 → 回答 → 修改条件 → 新答案」。这些接口使用应用自己的协议。

## 真实接入

需要先提供站内 Agent 创建入口对应的官方配置或接入文档，再确定宿主托管模式、身份验证、事件去重与输出映射。开放平台 Access Secret 只解决工具调用权限。

真实模式还需核实搜索权限、全网结果归属、模型权限、延迟及引用的语义支持度。不得用 demo 结果替代站内联调记录。
