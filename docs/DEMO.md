# 演示脚本

演示开始前说明：当前未连接真实知乎时，页面明确标注「演示模式」，展示交互和一般性分析框架，不展示虚构来源。

1. 输入「如何评价中山大学？」。看到目的卡片，选本科报考，点击继续。
2. 输入计算机，关注点选就业发展/学习体验，点击继续。核对聚焦问题，点击开始分析。
3. 展示检索/整理阶段以及按两个关注点展开的框架。
4. 点击「修改条件再问」，改为校园生活，移除之前关注点，选择住宿条件/交通出行，保存并重新分析。展开此前回答，对照两个版本。
5. 开启新提问，输入「中大计算机本科课程体验怎么样？」。展示明确问题直接进入回答。
6. 开启新提问，输入宽泛问题；不做选择，点击「跳过，直接回答」。展示不用填写背景也能继续。
7. 刷新页面，当前会话恢复；给回答提交有帮助或不太相关的反馈。

真实模式联调完成后，补充展示返回来源的标题、作者、摘要、原始链接，以及引用是否支持正文。没有获取到来源时，按页面真实提示说明状态。
