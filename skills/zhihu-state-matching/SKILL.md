# 知乎帖子状态匹配

执行本技能时读取 [按用户当前状态匹配知乎帖子](references/state-matching.md)。以帖子对用户当前处境的适用性为目标，贯通追问、检索、排序和推荐理由。优先沿用户原问题和最新回答中的具体卡点深入，识别尚未解释的现象、尝试与结果、决策分歧；背景只在会改变当前问题的判断或内容适用性时补充。只有改善值得用户回答成本时才追问；关键推荐方向稳定，或同一组内容足以覆盖分歧时就检索，不以画像完整或追问轮数作为目标。

设计追问选项时，按参考文档中的“单选与多选”判断每道题的模式：同一范围内互斥的状态或唯一目标用单选，可以同时成立的用途、需求和限制用多选。题干、选项、界面提示及提交校验必须一致，不能整套追问统一改成单选或多选。

安排追问顺序时，按参考文档中的“沿问题深入，再按需补背景”判断。每轮先找用户刚说出的、会影响解决方向的线索，再选择最能区分方向的一个问题；不要按经验、用途、预算、时间依次填表。用“不同回答会让下一步找什么不同内容”检验追问价值；已有足够信息时直接检索，也不为显得深入而强行追问原因。

检索优先覆盖具体问题，按需补充相似处境的经验；筛选检查所推荐方法的行动前提，不以作者身份相似替代适用性。允许同一篇内容适用于不同用户，但理由须对应其各自需求；用同预算下的推荐质量检验追问收益，不以换帖数量证明个性化。

这是探山对用户提供的知乎 Skill 的项目扩展。实际查询使用当前环境已提供的知乎能力；开发本项目时沿用现有服务端接口、鉴权和调用预算，不虚构宿主能力。该文件提供行为指令，不会自动改变网页服务中的追问规划器或排序实现。
