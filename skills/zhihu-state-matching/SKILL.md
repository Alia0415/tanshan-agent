# 知乎帖子状态匹配

执行本技能时读取 [按用户当前状态匹配知乎帖子](references/state-matching.md)。以帖子对用户当前处境的适用性为目标，贯通追问、检索、排序和推荐理由。不能仅凭“已工作”“想转行”等粗标签就判断信息充分；按需追问会影响适用性的具体起点、目标、已有尝试和现实限制，直到足以区分关键推荐方向，或用户选择停止。

这是问山对用户提供的知乎 Skill 的项目扩展。实际查询使用当前环境已提供的知乎能力；开发本项目时沿用现有服务端接口、鉴权和调用预算，不虚构宿主能力。该文件提供行为指令，不会自动改变网页服务中的追问规划器或排序实现。
